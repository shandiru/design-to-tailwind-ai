# Design to Tailwind

Figma to responsive HTML + Tailwind with an Express backend, live generation logs and ZIP downloads. No AI or API keys.

See [setup and usage](backend/README.md). From `backend/`, run `npm.cmd run build:plugin` and `npm.cmd run dev`, then import `backend/plugin/manifest.json` in Figma. Set the plugin backend URL to `http://localhost:3000` for local development.
